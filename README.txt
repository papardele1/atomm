ATOMM — установка на сервер 82.114.226.70
==========================================

ПЕРЕД УСТАНОВКОЙ
1. У регистратора домена atomm.store добавьте две A-записи:
     atomm.store      →  82.114.226.70
     www.atomm.store  →  82.114.226.70
2. Создайте бота в Telegram у @BotFather и держите его токен под рукой
   (токен никому не пересылайте — его попросит сам установщик).

УСТАНОВКА (команды вводятся на вашем компьютере)
1. Скопируйте архив на сервер:
     scp atomm.zip root@82.114.226.70:/root/
2. Зайдите на сервер:
     ssh root@82.114.226.70
3. Распакуйте и запустите установку:
     apt-get install -y unzip && unzip -o atomm.zip && sudo bash atomm/install.sh
4. Установщик попросит токен бота, потом — отправить боту /start.
   В конце спросит e-mail для HTTPS (можно пропустить, нажав Enter).

ПОЛЕЗНОЕ
  Сайт сразу открывается по http://82.114.226.70
  HTTPS позже (если DNS ещё не обновился):   sudo bash /opt/atomm/enable-ssl.sh
  Лог парсера цен:                           journalctl -u atomm-parser -f
  Запустить парсер вручную:                  sudo systemctl start atomm-parser
  Последние заказы:                          sqlite3 /var/lib/atomm/orders.db 'select id,created,name,phone,total from orders order by id desc limit 20'
  Обновление сайта новой версией пакета:     распаковать новый atomm.zip и снова запустить sudo bash atomm/install.sh

ЧТО РАБОТАЕТ
  • Сайт: главная, каталог (~6 000 товаров), корзина, оформление заказа.
  • Заказы сохраняются в базе на сервере и приходят вам в Telegram.
  • Оплата: наличными при получении; карта — «временно недоступна по техническим причинам».
  • Парсер обновляет цены по Store77 каждые 4 часа (цены ATOMM = −0,5 %).
    Если сбор неполный (например, Store77 заблокировал сервер), старый каталог не перезаписывается.
  • Если Store77 начнёт блокировать сервер, впишите ваш 4G-прокси в /etc/atomm/env
    (строка ATOMM_PROXY=...) и выполните: sudo systemctl start atomm-parser

ДО ЗАПУСКА ПРОДАЖ
  • Заполните жёлтые поля на странице /privacy.html (ИП/ООО, ИНН, адрес, e-mail):
    файл /var/www/atomm/privacy.html.
  • Для приёма наличных нужна онлайн-касса (54-ФЗ).
